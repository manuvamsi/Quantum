# IMPORTANT — Xavier NX / JetPack 5.x (Ubuntu 20.04) notes:
#   * JetPack 5 ships Python 3.8, but pennylane/pennylane-lightning 0.44 need
#     Python >= 3.11. Install python3.11 from the deadsnakes PPA first

#   * chromadb needs sqlite >= 3.35 but Ubuntu 20.04 ships 3.31; setup_jetson.sh
#     builds a newer libsqlite3 into /usr/local (python picks it up via ldconfig).
#
#   pip install -r requirements-jetson.txt
